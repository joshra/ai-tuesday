/02 About

What is
AI Tuesday?

A low-pressure, recurring, technically-focused lunch meetup where engineers, product builders, and researchers share real-world experiences with AI tools, projects, workflows, and product observations — building up a reusable, openly documented body of knowledge through discussion.

No polished deck required. No need to frame it as a formal talk. Good shares can be short — the point is what you actually tried, how it went, what worked, and what didn't.

/04 Positioning
AI Tuesday is ——
  • A low-pressure, recurring, technically-focused lunch meetup
  • A place to share hands-on experience, lessons learned, and tool evaluations
  • A peer-to-peer space for engineers, product builders, and researchers
  • A community that builds shared notes, openly and incrementally

Not ——

/05 Agent-Native

Humans set direction,
agents handle the routine.

AI Tuesday is designed as an agent-native community: humans build trust, make judgment calls, and own final decisions; agents handle note-taking, topic summaries, session prep, and progress tracking.

This isn't an automation experiment — it's about offloading the recurring admin work of each meetup to agents so that human attention stays on real technical discussion.

AGENT / 01
Host Assistant
Drafts the agenda, generates opening prompts, tracks speaker confirmations, and sends post-session reminders.
AGENT / 02
Notes Compiler
Structures post-session notes into Markdown, tags topics, and checks for sensitive content before publishing.
AGENT / 03
Curation Agent
Summarizes weekly themes, categorizes links and tools shared by members, and drafts the weekly digest.
AGENT / 04
Onboarding Guide
Welcomes new members, surfaces relevant past notes, and helps reframe questions for more focused discussion.
AGENT / 05
Talk Prep
Helps speakers shape rough notes into a 15-minute outline and anticipates likely audience questions.
AGENT / 06
Knowledge Base Agent
Indexes past notes by topic with semantic search, producing topic maps and suggested learning paths.

Join AI Tuesday

We run a small AI tech sharing group called "AI Tuesday" — every Tuesday at noon for 50 minutes online. Topics lean practical: AI coding, agent workflows, tool reviews, paper readings, and product observations. This isn't a course or a marketing channel; it's peer exchange among engineers and product practitioners. If you're into AI tools or applied AI, you're welcome to join as a listener or occasional speaker.
